# Facets 0.9.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `findFacets` (region growing on 0.7.0 normals: per-point facet ids; per facet plane, dip / dip direction, area, rms, closed 3D outline) and `jointSets` (automatic / count / windows, Fisher statistics, per-point set ids); the demo gains a Facets tab with its own SVG stereonet.

**Architecture:** `src/facets/orientation.js` holds the pole / dip / dip-direction convention and the Fisher statistics; `outline.js` the in-plane grid (area and outline); `findFacets.js` the growth on the 0.7.0 k-d tree and normals; `jointSets.js` the axial mean-shift, k-means and windows. The demo's tab lives in `examples/browser/facets.js`, the net in `stereonet.js`.

**Tech Stack:** plain ES modules, `node:test`, no dependencies; Three.js in the demo only.

**Spec:** `docs/design/2026-10-23-facets-0.9.0-design.md`

## Global Constraints

- No dependencies in las-laz-js; no WASM. trimesh-build-js depends on las-laz-js: never import it.
- Code style as the repo: `var`, `function` declarations, tabs, a `// src/…` banner block at the top of each new file, JSDoc on every export, `/* prettier-ignore-file */` in tests.
- Errors are `LasError` `ERROR_CODES.INVALID_ARGUMENT` with a message naming the argument.
- Convention (spec §2): pole = unit normal with z > 0 (a vertical one by `orientNormal`: x > 0, then y > 0); dip = acos(n_z) degrees 0–90; dipDirection = `(atan2(n_x, n_y) · 180/π + 360) % 360`, 0 when dip is 0; x east, y north, z up.
- `findFacets` defaults: `k` 16, `maxAngle` 10, `planeDistance` 3 × `estimateNoise` (or `maxDistance` / 10 when NaN), `minArea` 1, `minPoints` 20, `outlineCell` 2 × the facet's median nearest-neighbour spacing; `maxDistance` required (0.7.0 message). Plane refit when the count passes 1.25 × the count at the last fit. Facet ids 1 … n by area, largest first; 0 = none.
- `jointSets` defaults: automatic, `maxAngle` 15, `minFacets` 3; mean-shift seeds = every pole or an even 2,000; converge at < 1e-6 rad or 50 steps; merge modes within `maxAngle` / 2. Fisher: weights scaled so Σw = N; K = (N − 1)/(N − R); cone95 = acos(1 − (N − R)/R · (20^(1/(N − 1)) − 1)) degrees; NaN for N < 2.
- Every new public function is exported from `src/index.js` in the task that writes it: `findFacets`, `jointSets`, and `dipDirection` helpers as spec'd (`poleOf`, `orientationOf`, `poleFromOrientation`).
- Tests are oracles (planes and poles by construction, hand-computed statistics), never snapshots.
- `npm test` passes after every task. Coverage after the last task: no metric below lines 99.76, branches 97.24, functions 98.36 (0.8.0).
- Private samples named by id only; `npm run check:private` after staging, before every commit.

## Review Focus

1. **Overhangs and walls facing every way** (a pit wall's faces dip in all directions, some past vertical as seen from the pole rule): a plane dipping 80° to 350° and one dipping 80° to 10° must report dip directions 350 and 10, not folded to one side; a facet whose fitted normal points down must report the same dip / dip direction as its up-pointing twin. → Task 1 test.
2. **A selection in local Float32 coordinates at UTM origin** (the demo passes the selected points of a `localOrigin` read): results identical (normal 1e-6, area 0.1 %) to the same planes in Float64 at the origin. → Task 3 test.
3. **One huge facet (a 20 M-point bench floor):** growth stays linear — 4 × the points takes < 6 × the time — and memory beyond the documented ~30 bytes a point does not grow with facet size (the refit uses running sums, never a per-facet point copy). → Task 3 test (timed, skipped under coverage).
4. **Joint sets that straddle the horizon** (sub-vertical joints whose poles are near-horizontal, half pointing each way): one set, not two, with its mean dip near 90 — the axial treatment must hold across the antipode. → Task 4 test.
5. **Stereonet poles on the primitive circle** (dip 90 facets): plotted on the circle, never off the net or NaN; a cone that crosses the primitive wraps to the opposite side. → Task 6 browser check.

  - `"axial: a pole and its opposite are one"` — fisherStats of (0, 0, 1) and (0, 0, −1) → mean (0, 0, ±1), R = 2; `angleBetweenAxes([1,0,0], [-1,0,0])` = 0.

  - `"a hole is not traced"` — a 10 × 10 square with a 2 × 2 hole: area within 3 % of 96; the outline's shoelace area within 3 % of 100.
