Writes the points read (with every field the format holds) as a new LAS file with writeLas, then reads it back to check the round trip. A browser page holds at most 5,000,000 points for this, thinned evenly; to write more, stream with createLasWriter.

las-laz-js reads and writes ASPRS LAS point clouds in plain JavaScript, with no dependencies, in the browser and Node. LAZ (LASzip) files are read too; writing LAZ arrives in 0.3.0. The LAZ decoder is translated from laz-rs (Apache-2.0).

Big files stream through in windows of whole records, never held whole. This page draws with Three.js; the library itself has no dependency.
