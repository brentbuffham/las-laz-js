Writes the points read (with every field the format holds) as a new LAS or LAZ file with writeLas, then reads it back to check the round trip. After an edit it writes the edited cloud instead: the fields read (x y z, class, intensity, return, colour). A browser page holds at most 5,000,000 points for this, thinned evenly; to write more, stream with createLasWriter.

las-laz-js reads and writes ASPRS LAS point clouds in plain JavaScript, with no dependencies, in the browser and Node. LAZ (LASzip) files are read and written too. The LAZ decoder and encoder are translated from laz-rs (Apache-2.0).

Big files stream through in windows of whole records, never held whole. This page draws with Three.js; the library itself has no dependency.
