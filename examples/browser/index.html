Splits the selection (draw a polygon round the wall, Inside polygon) or the whole cloud into facets, flat patches, with findFacets, and groups them into joint sets with jointSets. Dip 90 is vertical; dip direction is a bearing from north. The page pauses while it runs.

Joint sets

Splits the selection (draw a polygon round the muckpile, Inside polygon) or the whole cloud into fragments, rocks, with findFragments: facets that meet at a ridge are one rock, a valley keeps two apart. Size is a fragment's intermediate axis b, the sieve-size estimate. Only the visible surface is measured; a flat floor or fines flat at this scale come out as fragments too, so keep the run to the pile. The pile faces up; for a drawpoint or a steep face, look at it from the open side and tick Camera as viewpoint. The page pauses while it runs.

Fragments

A grid of the highest point per cell; relief is the height above the local mean surface. Each relief peak standing at least Seed height proud seeds a rock and floods down to where it meets its neighbours; the gaps under the mean surface stay in no fragment. Seen from above only: for a drawpoint or a steep face use Facets.

Writes the whole file — every record that passes the Read tab's class, return, bounds and crop filters, with every field the format holds; Max points only limits what is read for viewing — as a new LAS or LAZ file, streamed in batches through createLasWriter, then checks the count in the written header. After an edit it writes the edited cloud instead (the points read, so set Max points to 0 to edit every point): the fields read (x y z, class, intensity, return and number of returns, colour, extra bytes); a Split cloud is saved whole, both parts. Extra bytes are kept either way (the deprecated array types are read, not written). Save with facet / set saves the cloud as read with two more extra-bytes fields, facet and joint_set. In Chrome and Edge the file goes straight to disk through the Save dialog, at any size; other browsers build it in memory and download it.

las-laz-js reads and writes ASPRS LAS point clouds in plain JavaScript, with no dependencies, in the browser and Node. LAZ (LASzip) files are read and written too, and point columns can be selected (box, polygon, class, sparse points, outliers), kept, deleted, split, merged, classified, transformed, smoothed (denoised), registered (to the grid by control points, or to another cloud by picked pairs and ICP), split into facets and joint sets, and into fragments (rocks) with their size curve, and searched with a voxel neighbour index. The LAZ decoder and encoder are translated from laz-rs (Apache-2.0).

Big files stream through in windows of whole records, never held whole. This page draws with Three.js; the library itself has no dependency.
